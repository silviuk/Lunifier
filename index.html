Lunifier

Seamless multi-border screen switching for Logitech Easy-Switch keyboards and mice across Windows & Linux
🐧 Linux (Ubuntu / Debian) 🪟 Windows 10 / 11 ⚡ Zero LAN/Wi-Fi Req. 🖱️ Logitech Flow Alternative

🐧 Linux Installation (Ubuntu, Debian & Derivatives)

Option 1: One-Line APT Install (Recommended — Automatic Updates) Easiest

Configures repository keyring and sources list, then installs Lunifier with automatic updates via standard apt upgrade:

curl -fsSL https://silviuk.github.io/Lunifier/install.sh | sudo bash
Option 2: Standalone Debian Package (.deb)

Download and install the standalone deb package directly:

# Download the latest .deb from Releases and install
sudo apt install ./lunifier_all.deb
Manual Step-by-Step APT Keyring & Sources Setup 
# 1. Add repository GPG signing key
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://silviuk.github.io/Lunifier/key.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/lunifier.gpg

# 2. Add repository to sources list
echo "deb [signed-by=/etc/apt/keyrings/lunifier.gpg] https://silviuk.github.io/Lunifier stable main" | sudo tee /etc/apt/sources.list.d/lunifier.list

# 3. Update & install Lunifier
sudo apt update
sudo apt install lunifier

Multi-Border 3-Channel Architecture

Lunifier transfers your Logitech peripherals simultaneously when the cursor dwells against any configured screen edge:

⚡ Zero LAN / Wi-Fi Dependency Operates autonomously on each host over direct Bluetooth, Logi Bolt, and Unifying receivers. Works seamlessly across VPNs, guest networks, and corporate firewalls.
🎛️ Logitech HID++ 2.0 Feature 0x1814 Transmits hardware CHANGE_HOST commands directly to all connected Easy-Switch keyboards and mice simultaneously for sub-second switching.
🖥️ Multi-Border Screen Routing Independently route Left, Right, Top, or Bottom screen edges to distinct channels (Channel 1, 2, or 3) to coordinate 2-PC or 3-PC desk setups.
🐧🪟 Cross-Platform Parity (Linux & Windows) Full parity with system tray controls, configuration GUI, background services (systemd / Windows startup), and optional Bluetooth RFCOMM entry alignment.
