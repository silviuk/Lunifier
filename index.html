Lunifier APT Repository

Seamless Logitech Easy-Switch keyboard & mouse switching across Windows & Linux

Ubuntu / Debian Quick Install Recommended

Run this command in your terminal to configure the APT repository and install Lunifier in one step:

curl -fsSL https://silviuk.github.io/Lunifier/install.sh | sudo bash
Manual Step-by-Step APT Configuration 
# 1. Add repository GPG signing key
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://silviuk.github.io/Lunifier/key.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/lunifier.gpg

# 2. Add repository to sources list
echo "deb [signed-by=/etc/apt/keyrings/lunifier.gpg] https://silviuk.github.io/Lunifier stable main" | sudo tee /etc/apt/sources.list.d/lunifier.list

# 3. Update & install Lunifier
sudo apt update
sudo apt install lunifier

Multi-Border 3-Channel Architecture

Lunifier transfers your Logitech peripherals simultaneously when the cursor dwells against any configured screen edge:

⚡ Zero LAN / Wi-Fi Dependency Operates autonomously on each host over direct Bluetooth, Logi Bolt, and Unifying receivers. Works seamlessly over VPNs and guest networks.
🎛️ Logitech HID++ 2.0 Feature 0x1814 Transmits hardware CHANGE_HOST commands simultaneously to all connected Easy-Switch peripherals for sub-second switching.
🖥️ Multi-Border Screen Routing Independently assign Left, Right, Top, or Bottom screen edges to distinct channels (Channel 1, 2, or 3) for 2-PC or 3-PC desk layouts.
🐧 Cross-Platform (Linux & Windows) Full support for Ubuntu, Debian, and Windows 10/11 with system tray controls, desktop integration, and systemd service autostart.
