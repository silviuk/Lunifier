### Lunifier v1.0.4 Release Notes

#### What's New in v1.0.4
- **About Tab**: Added comprehensive application details, MIT license, copyright, third-party library acknowledgments, and clickable links to GitHub and Issue Tracker.
- **System Tray Icon & Quick-Switch Mini Window**: Continuous background presence in the system tray with 1-click simultaneous and individual device switching, plus a sleek popup mini window. Closing the main window minimizes to tray.
- **Bluetooth Partner Discovery & Handshake Protocol**: Built-in scanning of paired and nearby Bluetooth PCs, complete with an interactive pairing handshake request/accept/reject workflow to bind partner machines.
- **Modern 12px Border Guideline**: Redesigned glowing neon light-bar visual overlay with high-contrast accent borders and radiant core for improved edge visibility.
- **Fixed Border Knock Detection**: Implemented release-before-second-knock state machine to prevent false triggers during continuous edge touches.
