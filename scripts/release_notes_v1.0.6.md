### Lunifier v1.0.6 Release Notes

#### What's New in v1.0.6
- **Unified Branding & Master Iconography**:
  - The official Lunifier star-squircle icon is now consistently displayed across all platforms, windows, dialogs, system tray, and operating system taskbars.
  - Windows taskbar and Alt+Tab switchers now explicitly register under `silviuk.lunifier.app.1.0`, preventing fallback to generic Python or default Tk feather icons.
  - Quick Switch mini window popup now displays the branded Lunifier icon on both taskbar and window header.
  - Added the high-resolution Lunifier branding asset directly into the main application header and About information tab.
- **Packaging & Manifests**:
  - Full suite of distribution packages built and verified for Windows (Inno Setup Installer, Portable ZIP, MSIX) and Linux (Debian `.deb`, Standalone `.tar.gz`).
  - WinGet community repository manifests updated and verified for v1.0.6.
