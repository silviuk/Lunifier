Get started

Ready in a few steps.

What you’ll need

Windows 11 or a supported Linux desktop (the native Linux UI targets Ubuntu 24.04+) for each host, compatible Logitech Easy-Switch peripherals, and Bluetooth, Unifying, or Logi Bolt connections supported by your devices. Pair the devices with every host before configuring Lunifier.

  1. Pair your compatible keyboard and mouse with each computer on its own Easy-Switch channel.
  2. Install Lunifier on each host and select that computer’s channel.
  3. Assign screen edges to the other channels, then move to an edge to switch.

Read the project guide ↗

Hardware support depends on the device’s HID++ Easy-Switch features. Bluetooth peer features are optional and off by default. Lunifier is an independent project, unaffiliated with Logitech.

Linux installation

Download a Debian package from Releases, or use the APT repository for updates:

curl -fsSL https://silviuk.github.io/Lunifier/install.sh | sudo bash

This command downloads and runs the installer with administrator privileges. Read install.sh first. Package metadata and existing downloads remain available at this URL.
